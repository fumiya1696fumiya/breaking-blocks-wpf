# Breaking Blocks (ブロック崩し)

## 概要
WPFを使用して作成したブロック崩しゲームです。

## 使用技術
- C#
- WPF
- MVVM（CommunityToolkit.Mvvm）

## 主な機能
- ボールとブロックの当たり判定
- スコア表示
- ゲームオーバー処理

## 工夫した点
- 当たり判定ロジックを自作し、処理の理解を深めた
- MVVMパターンを意識して、Viewとロジックを分離した
